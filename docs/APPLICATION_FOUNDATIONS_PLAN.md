# アプリケーション基盤の実装と検証計画

対象は共通GUIとKaname。以下の全項目を完了対象とし、一部の実装で全体完了とはしない。

| 項目 | 完了条件 | 現在 |
| --- | --- | --- |
| 公開APIの棚卸し | 空実装・固定成功値・実装済みを分類し、未対応を呼出側が検出可能 | 未完了 |
| フォーカス | Tab/逆順、Enter/Space、表示、非表示/無効除外、入力欄・ダイアログ範囲制限 | 着手 |
| イベント配送 | 最前面優先、消費、ドラッグ捕捉、背後の操作抑止 | 未完了 |
| IME | 未確定文字、候補位置、選択置換、確定キーの二重実行防止、OS別試験 | 未完了 |
| 非同期 | 実タスク、UIスレッド完了通知、失敗、進捗、取消、終了時寿命 | 未完了 |
| レイアウト | 最小/最大、伸縮、内容計測、折返し、入れ子のクリッピング | 未完了 |
| 共通アクション | ボタン/メニュー/キーで状態と実行を共有、モーダル/入力中の文脈 | 未完了 |
| 編集履歴 | 複合操作、連続入力統合、保存点、Kanameの既存安全性を維持 | 未完了 |
| アクセシビリティ | OSへの部品ツリー公開、名前/役割/値/状態/操作、読み上げ実機試験 | 未完了 |

## 検証方針

## 進捗 2026-11-14

- ボタン・小ボタン・一覧行にウィンドウ単位のフォーカス順序と枠を追加。
- `フォーカストラバーサル(真)` で有効化。初期値は無効として既存アプリの独自キー処理を維持。
- Tab/Shift+Tab、Enter/Spaceの一度だけの消費、非表示対象の解除、無効対象の除外をネイティブ入力再現で検査。
- 入力欄（単一行・パスワード・複数行）とチェックボックス・ラジオボタンを共通フォーカス順序へ接続。入力欄からのTab移動と非表示時の解除を追加。
- 無効入力欄の編集抑止と、入力欄→チェックボックス→入力欄の正逆移動をネイティブテストで確認。
- モーダルとIMEの統合は未完了なので、Kaname全体への有効化はまだ行わない。
- `モーダル予約` により、背景入力とフォーカス登録を抑止し、予約名に一致するダイアログへ入力を配送。開始操作の再配送を防ぎ、終了後のフォーカスを復帰。
- Kanameの保存確認・新規作成・ノベルコマンド追加・名前変更に予約を採用。複数モーダルのスタック、旧マップ/イベント系ダイアログ、OS実入力・IMEとの統合検査は残る。
- `node tests/audit-api-stubs.mjs` で空実装・固定値返却の候補をJSON列挙。静的な候補抽出であり、全APIの完成判定や厳密な分類ではない。
- macOSのNSTextInputClientに未確定文字・選択範囲・部分文字列・候補座標を実装。変換中のキーを通常のKEYDOWNへ二重配送しない。
- GUIに未確定状態、単一行入力の下線表示、IME状態取得を追加。入力上限でUTF-8の途中切断を防止。
- Cocoaクライアントへの直接呼出で、未確定範囲・候補座標・300文字の確定を検証。GUI側では変換中の削除抑止と確定文字挿入を検証。
- IME項目は未完了。公開IME合成コールバック、文書全体に対する選択/置換範囲、長い未確定文字、複数行での未確定表示と候補座標、実IMEでの操作、Windows/Linux接続は残る。
- POSIXプロセスタスクの開始・成功/失敗・強制取消・子の回収・状態解放・終了時回収を実装。起動失敗や未対応の任意関数形式は-1とし、偽の進捗100を廃止。
- 明示的なタスク通知ポーリングで、完了コールバックをGUIスレッドへ一度だけ配送。言語クロージャをバックグラウンドで保持しない。
- ネイティブ試験で起動失敗・状態・所有権・保持上限・取消/終了時回収を確認。公開API試験で待機中のGUIフレーム継続と終了コード7、通知一回を確認。
- 非同期項目は未完了。任意関数の隔離実行、自動完了購読、途中進捗IPC、Windows、Kanameでの重い処理への適用は残る。
- 共通アクション登録・ボタン・メニュー・要求受取を実装。ラベルと有効状態を共有し、同フレームの実行は一度だけ。入力中の許可指定、IME中・モーダル背景の抑止に対応。
- Kanameの保存ボタン/メニュー/キー操作へ採用。画面描画後に保存要求を受け取り、フレーム内に作品を切り替えた場合の誤適用を防ぐ。
- ネイティブテストでキー/ボタン/メニュー要求、重複受取、入力中の許可、無効/IME/モーダル中の抑止を検査。Cocoaメニューの有効状態を直接検査。
- 共通アクション項目は未完了。高度なキー列と文脈階層、OS別の実入力、保存以外への展開は残る。編集履歴は引き続き別項目として未完了。
- `制約幅` で最小/最大/伸縮比による列幅配分を実装。収まらない場合は空配列で通知し、Kanameのホームでは縦配置へ切り替える。
- 子ウィンドウの親クリッピングを維持するよう修正。1万通りの数値検査（ASan/UBSan）、公開API、実描画の内外画素で検証。
- レイアウト項目は未完了。内容計測からの自動サイズ決定、一般フォームの折返し、縦方向制約、既存全画面への適用、OS別検査は残る。
- スナップショット履歴モデルを追加。Undo/Redo、統合キーによる連続編集統合、保存点、一括操作、取消、件数/メモリ予算、所有ウィンドウ終了時解放に対応。
- ASan/UBSanで1万回の編集、保存点、分岐、まとめ、失敗時の状態保持を検査。公開APIで操作とモデル数上限、破棄後ハンドルを検査。
- 編集履歴項目は未完了。Kanameの既存履歴からの移行、各編集操作の境界設定、実保存との保存点同期は次の実装対象。差分コマンドと永続化は現状のモデルには含まれない。

### 検証上の注意

ネイティブのフレーム入力テスト、公開API経由の描画、Kanameの回帰テストを分離する。
macOSのみの成功をWindows/Linuxの完成根拠にしない。API登録数は実装数ではない。
未対応を成功・進捗100として返す実装は完成扱いにしない。
言語のコールバックを根拠なく別スレッドで実行せず、ランタイムのスレッド安全性とGC寿命を検証する。
