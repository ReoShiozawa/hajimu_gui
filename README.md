# hajimu_gui

**はじむ言語用 GUI パッケージ v14.46.0** — 自作プラットフォーム層 + 即時モード GUI フレームワーク

通常の `ボタン` は `{"補助": 真}` で枠線主体の補助操作として表示できます。
`{"高さ": 44}` で最小標準高以上の高さを指定できます。幅は親領域内に制限されます。

### アプリケーション用部品

`テキスト入力` / `パスワード入力` / `数値入力` / `コンボボックス` はラベルの実幅に応じて配置します。
横に収まらない場合やラベルに改行がある場合は、ラベルを上に折り返し、入力欄を親幅内へ配置します。
部品の高さもフォントサイズに追従します。`フォントサイズ(0)` は既定値へ戻し、非有限値・負数・512を超える値は適用しません。
`数値入力` は有限な数値と正のステップを要求し、無効状態やモーダル背景ではホイールに反応しません。
コンボの開閉はウィンドウごとに独立し、非表示・無効化・モーダル変更で解除します。候補は最大8行でスクロールでき、上下キー選択と外部入力欄による検索に対応します。
新しい配置用APIは不要です。既存の呼出をそのまま利用できます。

#### 固定高一覧の仮想スクロール

`仮想スクロール(総数, 行送り)` は、現在の配置位置とウィンドウ/親スクロール/ダイアログの交差範囲から、固定高の可視行を返します。`開始` は0始まり、`終了` は含みません。`行送り` は行間込みの高さで、`0` は補足なしの `一覧項目` の現在の文字サイズと行間を使います。配置やスクロール状態は変更しません。
呼出側で `スペーサー(範囲["前余白"])`、可視行の描画、`スペーサー(範囲["後余白"])` の順に配置してください。省略した行の全高が保たれるため、スクロールバーも維持されます。縦方向の固定高一覧向けで、可変高行やツリーの展開管理、画面外へのキーボード移動を自動化するものではありません。
総数は0以上の整数、行送りは0以上の有限値を指定します。不正値・GUI外・扱えない全高は空範囲/余白0を返し、入力や配置を変更しません。

#### API対応状況

`API対応状態("非同期実行")` は、実バイナリの登録有無、最小/最大引数、状態、判定理由を返します。
状態は未登録・未実装・部分対応・固定返却/要確認・未検証です。未検証は「動かない」ではなく、機能全体やOS別の動作をこのAPIで保証していないことを表します。
固定返却の候補は自動抽出であり、意図した定数関数を含む可能性があります。逆に、複雑なスタブは検出できません。
`API対応一覧()` は全登録の情報を返します。診断用のため毎フレーム呼ばず、必要なときに取得してください。
判定APIは未実装関数の呼出を自動で禁止するものではありません。未実装の本実装と個別の動作検証は引き続き必要です。
`node tests/audit-api-stubs.mjs --write-header` で候補ヘッダーを更新し、`make audit-check` でソースとの一致を確認します。通常のCビルドにNode.jsは不要です。

#### macOSアクセシビリティのOS接続

ボタン・小ボタン・チェックボックス・ラジオボタン・一覧項目をNSAccessibilityの部品として公開します。
名前・説明・役割・チェック値・有効状態・画面座標を持ち、押下要求は対象ウィンドウのフレーム入力へ配送します。
`アクセシブル名` と `アクセシブル説明` は次の対応部品に適用し、消費後に解除します。`アクセシブルロール` のOSマッピングは現在checkbox/radioのみです。
要素はIDで再利用し、非表示の要素は公開ツリーから削除します。1ウィンドウ最大512要素で、超過部品は公開しません。
親の表示範囲外、無効状態、予約モーダルの背景では操作できません。ウィンドウ移動時は画面座標を再計算します。
`スクリーンリーダー通知("文章")` はmacOSの読み上げ要求通知を投稿できた場合に真を返します。実際に読み上げられたことの保証ではありません。未対応OSやウィンドウ外では偽です。

`テキスト入力` と `テキストエリア` は本文・文字数・選択文字列/範囲とフォーカスを公開します。
値全体の変更・選択文字列の置換・選択範囲の変更・フォーカス要求はキューへ入れ、GUIが処理した次の描画で状態を更新します。
通常入力・パスワード・複数行入力の本文は必要量に応じて拡張し、上限は1,048,575バイト（UTF-8、終端を除く）です。超過する挿入や確保失敗では本文・選択を保持します。初期値が上限以上なら入力欄を作らず元の値を返します。
範囲はCocoaのUTF-16位置から変換し、サロゲート途中を拒否します。macOSの文書/AX置換と未確定文字は、長文でも所有文字列を持つ1イベントで配送します。未確定文字のGUI側も最大1,048,575バイトまで必要量に応じて拡張し、本文とは分離して表示・通知します。変換中の選択範囲をハイライトし、その終点へカーソル・候補位置・表示を追従させます。
`IME状態()` と `IME合成` の通知には `選択開始` / `選択終了` を含めます。未確定文字内の0始まり・終点を含まないUnicode符号位置数で、UTF-8バイト数/UTF-16単位/見た目の文字数とは区別します。同一文字列でも範囲変更を通知します。
確保/容量/キュー不足では部分置換しません。macOSの文書接続外のTEXTINPUTも所有イベントで配送します。フレーム内の確定入力は最大1,048,575バイトまで集約し、集約の容量/確保不足では当該イベントを全体で拒否します。`アプリ入力状態` の `確定入力拒否数` はこの集約段階の累積拒否件数で、個々の入力欄の容量拒否を数えるものではありません。
LinuxのXIM確定文字は必要容量で一度再取得し、短い文字列は既存領域、長い文字列は所有イベントで配送します。上限超過・再度の容量不足・確保失敗・不正UTF-8では本文を部分配送しません。`XIM_SANITIZE=1 sh tests/check-xim-lookup.sh` は読取関数の戻り値を再現する検査であり、実IME操作の証明ではありません。
WindowsではIMM32の確定/未確定文字を所有イベントへ接続し、変換範囲と候補位置を入力欄へ合わせます。確定文字と次の未確定文字が同時に届いても、元の入力欄へ確定文字を一度だけ反映します。フォーカス喪失/入力停止では変換を取り消します。
`sh tests/check-win-ime.sh` はIMMの返却値を再現し、実Win32のUnicode変換とメッセージ処理を検査します。インストール済みIMEを操作する試験ではありません。
実IMEの候補操作/再変換、WindowsのTSF専用経路・従来のCS_INSERTCHAR/CS_NOMOVECARET経路、Linuxの未確定文字/候補位置と各OS実操作は残課題です。XIMを使わない旧キー入力経路の多言語対応も含めません。
無効/非表示/モーダル背景、IME変換中、未反映の本文変更がある間は編集を拒否します。容量不足やキュー不足で変更の一部だけを配送しません。
`パスワード入力` は保護された入力欄として公開し、フォーカス要求は受け付けますが、値・選択文字列・文字数の公開とAX経由の値編集は行いません。
値・選択・フォーカスの変更通知も投稿します。テーブル/ツリー構造、Windows/UIA、Linux/AT-SPIは未対応です。
Cocoa要素の直接取得と押下、入力欄の値/範囲編集、保護入力の非公開、無効/非表示の拒否、要素再利用、ヒットテスト、座標追従、寿命と上限をネイティブテストで確認しています。
VoiceOverによる実読み上げは未確認です。外部UI検査ツールはCLI起動の実行ファイルへ接続できなかったため、外部クライアント経由の確認は未完了です。
手動検査用の `tests/test_accessibility_window.jp` は名前付きボタンを一回押し、「検査終了」で閉じると成功を検査します。
設計は [AppleのNSAccessibility統合資料](https://developer.apple.com/documentation/Accessibility/integrating-accessibility-into-your-app) を参照しています。

#### 大量候補と検索

`コンボボックス(ラベル, 選択肢, 選択値[, 検索語])` は最大8行の候補をウィンドウ内へ配置し、下に収まらなければ上へ開きます。後続の部品を押し下げず、親のスクロール領域に切られない前面表示です。ホイール/スクロールバー、上下/Home/Endで移動できます。
開いている間は背景への入力を抑止します。外側のクリックは閉じるためだけに消費し、背後の操作を同時実行しません。非表示/無効/フォーカス喪失/モーダル切替/ウィンドウ終了で閉じます。
検索欄は既存の日本語入力欄と組み合わせます。検索中も現在値を保持し、一致候補がなくても値を変更しません。ASCIIは大小文字を区別せず、日本語はUTF-8の部分一致です。かな/幅/アクセントの正規化検索は行いません。

```jp
検索語 = GUI.テキスト入力("画像を検索", 検索語)
画像 = GUI.コンボボックス("基本画像", 画像一覧, 画像, 検索語)
```

描画用の複製は8行まで、1行1023バイトまででUTF-8境界を保って省略します。選択結果は元の値で、表示用の省略文字列には置換しません。候補の照合は全件走査ですが、描画は可視行だけです。ポップアップ内に独自のIME編集器は作らず、開く前に検索欄で絞り込みます。全OS実入力/支援技術での実操作は別途検証が必要です。

#### スナップショット編集履歴

`履歴作成(初期文字列, 最大Undo件数=50, バイト予算=8388608)` は正のIDを返し、失敗時は-1です。JSON等の完全なスナップショットを使います。

- `履歴追加(ID, 文字列, 操作名="", 統合キー="")`。同じ統合キーの連続操作はまとめます。保存点・Undo/Redo・一括操作を境に統合を止めます。
- `履歴戻す` / `履歴やり直す` は適用する文字列を返します。移動不可・無効IDは無です。実際の文書への適用は呼出側が行います。
- `履歴保存点(ID)` で現在地点を保存済みにします。`履歴保存点(ID, 偽)` は保存地点を無効化し、復旧直後などを未保存として扱えます。
- `履歴まとめ開始(ID, 操作名)` / `履歴まとめ終了(ID, 確定する)` で複数の追加を一回のUndoにします。入れ子は未対応です。取消時には `履歴現在(ID)` の文字列を文書へ戻してください。
- `履歴状態(ID)` はUndo/Redo可否、保存済み、まとめ中、件数、保持バイト数、Undo/Redoの操作名を返します。
- `履歴破棄(ID)` で解放します。ウィンドウ内で作った履歴はそのウィンドウの終了時にも破棄します。ウィンドウ外で作った履歴は明示的な破棄が必要です。

GUI全体で最大16モデル、Undo上限1〜1000件、保持予算は最大64MiB/モデルです。件数には現在地点を含むのでUndo上限+1地点を保持します。
保存点を含む古い地点が上限により破棄されると、その地点へUndoで戻ることはできません。保存済み判定は地点の識別子によるもので、同じ文字列を手動で再入力したかは比較しません。
グループの編集中スナップショットも保持予算へ含めます。予算不足・確保失敗の追加は偽を返し、元の履歴を保持します。処理中の一時コピーと管理構造体は予算外です。
データはNULを含まない文字列です。差分コマンド、ディスク永続化、自動的な編集検出を実装するAPIではありません。
`sh tests/check-history.sh` と `tests/test_history_api.jp` で検証できます。Kanameの既存履歴からの移行はまだ完了していません。

#### 制約による幅配分

`テキスト` / `折返しテキスト` / `テキスト測定` は同じ行分割・行高さを使います。
第2引数に `{"幅": 360, "サイズ": 20, "行高さ": 30, "色": "#285F9B"}` を指定できます。数値だけなら文字サイズです。
描画時の幅は親の利用可能幅以下に制限し、測定時は指定幅で折り返します。測定の幅省略は改行だけで分割します。
`テキスト測定` は `幅`（最大行の送り幅）・`高さ`（配置に必要な高さ）・`行数`・`行高さ` を返します。
フォントや描画状態、配置位置、直前の部品、次部品の幅指定は変更しません。以前のインク境界の高さとは異なり、描画と同じ配置用の高さです。
空文字は1行、末尾改行の次にも空行を確保し、CRLFは1つの改行として数えます。64行を超えても継続します。
行高さの既定値は文字サイズの1.4倍です。サイズは0より大きく512以下、行高さは文字サイズ以上、幅は正の有限数が必要です。
未知の設定名や不正な値は無を返します。描画も行いません。描画時は親のクリップと交差してはみ出しを抑えます。
書記素単位の折返しであり、単語境界・日本語の禁則処理・字形合成の完全対応ではありません。
検査は `tests/test_text_block.jp` と `sh tests/check-application-controls.sh` で実行できます。

`制約幅([{"最小": 120, "最大": 200, "伸縮": 1}, {"最小": 200, "伸縮": 2}], 全幅, 間隔)` は各列の幅を配列で返します。
最小幅の確保後に残りを伸縮比で分配し、最大幅に達した列を除外して残りを再配分します。
`伸縮: 0` は最小幅のままです。既定値は最小0・最大FLT_MAX・伸縮1・間隔8です。
最小幅の合計と間隔が全幅に収まらない、型や値が不正、列数が1〜64以外の場合は空配列を返します。
空配列の場合は縦配置などへ切り替えてください。計算はGUI作成前にも利用できます。
戻り値を既存の横並び・子ウィンドウの幅に渡します。配置やクリッピング、内容計測は自動で行うAPIではありません。
`sh tests/check-layout.sh` で数値計算を、`sh tests/check-layout-api.sh` で公開APIと入れ子の描画クリップを検査できます。

#### 共通アクション

描画コールバックの先頭で `アクション登録("save", "保存", {"キー": "s", "修飾": "Ctrl", "有効": 真, "入力中": 真})` を呼びます。
`アクションボタン("save")` と `アクションメニュー("save")` は同じラベル・有効状態・実行要求を共有します。
描画の後に `もし GUI.アクション受取("save") なら ... 終わり` で一度だけ実行してください。表示関数の戻り値を実行判断には使いません。
登録は毎フレーム必要で、登録のない要求を次フレームへ持ち越しません。同じIDの再登録でも実行済みフラグは維持します。
入力中のキー実行は既定で抑止し、`入力中` で明示許可できます。IME変換中・予約モーダルの背景・無効化範囲では抑止します。
キー要求は登録順に消費します。同じショートカットを持つ複数の有効アクションは最初のものを優先します。
最大64件/ウィンドウ/フレーム、IDは127バイト・表示名は255バイト以内です。上限超過は登録時に偽を返します。
現在のキー指定は既存ショートカットAPIの対応キーに限ります。複数段キー列・任意キー・自動的な文脈階層は未対応です。
macOSネイティブメニューは有効状態の更新に対応していますが、初期構築後に登録ラベルやショートカットを変える用途は未対応です。

#### 開発中のプロセスタスク

Windows専用の検査は `sh tests/check-win-tasks.sh` です。実際の子プロセスを使い、Unicode引数、出力/進捗、子孫の取消、起動失敗とハンドル寿命を確認します。OSの初回初期化は同じWin32 APIの直接呼出を対照にし、反復後のハンドル数は基準値との完全一致を要求します。Kaname全体のGUI実操作の代替ではありません。

macOS/Linux/Windowsの `非同期実行({"実行ファイル": "/path/to/worker", "引数": ["arg"]}, 無)` は実タスクIDを返します。起動失敗・未対応形式は `-1` です。
実行ファイルと引数は直接渡し、シェルを暗黙には起動しません。既定では標準出力・標準エラーを親から継承します。埋め込みNULは拒否します。
WindowsはUTF-16の実行ファイルパスとMSCRT互換の引数引用を使い、不正UTF-8や長すぎるコマンドは拒否します。`.bat` 等を動かす場合は明示的に `cmd.exe` を指定してください。標準入力はNULへ接続し、親の端末入力を奪いません。
設定辞書の `"出力取得": 真` で両出力を別々に捕捉し、`"進捗取得": 真` で専用の進捗パイプを追加できます。両方とも省略時は偽です。

- `タスク状態(ID)` は「状態」（実行中・成功・失敗・取消中・取消・不明）と「終了コード」「進捗」「エラー番号」を返します。
- 正常終了時の終了コードは子の値。POSIXのシグナル終了時は128+シグナル番号です（SIGKILLなら137）。Windowsは符号なし32ビットの終了値を保持し、終了済みなら259も有効な終了コードとして扱います。
- `タスク進捗(ID)` は正常終了時に100、実行中は報告された割合（上限99）、未報告/失敗/取消/不明IDは `-1` です。失敗や取消との区別には状態を使ってください。
- 描画コールバック内で毎フレーム `タスク通知(ID, 関数(結果): ... 終わり)` を呼ぶと、終了後に一度だけその呼出元で通知します。バックグラウンドに言語クロージャを保持しません。
- `タスクキャンセル(ID)` はPOSIXのプロセスグループ/Windowsの専用Jobへ強制終了を要求し、要求を受理した場合に真を返します。終了回収を待たずに戻り、状態を「取消中」にします。重複要求は偽です。
- 「取消中」のPIDと出力を保持し、描画ループの監視またはタスクAPIの呼出時に非ブロッキングで回収します。回収後は「取消」となり、実際の終了コードを保持します。取消要求失敗時は実行状態を保持し、「エラー番号」を返します。
- 取消要求の受理は完了通知ではありません。「取消中」の解放は拒否し、完了コールバックは回収後に一度だけ配送します。処理途中のファイルのロールバックは行いません。
- `タスク解放(ID)` は終了済みの状態を解放します。ウィンドウごとに所有権を管理し、GUI全体で最大32件を保持します。
- GUI描画ループ終了時・アプリ破棄時に、所有する実行中タスクを停止・回収します。異常終了や子が独自にデーモン化する場合の回収は保証しません。

`タスク出力(ID)` は `有効`・`取得有効`・`標準出力`・`標準エラー`・各出力の `バイト数` / `切詰め` / `読取エラー` を返します。
例として標準出力のキーは `標準出力バイト数`・`標準出力切詰め`・`標準出力読取エラー` です。
各ストリームの末尾16KiBを保持し、超過すると古い出力を捨てて切詰めを真にします。読取り自体は継続します。
文字列APIなのでNUL/不正UTF-8はU+FFFDへ置換し、受信途中のUTF-8文字は保留します。バイナリ出力の完全保存には使えません。
`読取終了` は両出力パイプが閉じたか、`読取完了` は両方のEOFまで受け取れたかを表します。エラー番号はPOSIXのerrno/WindowsのWin32エラー値（0ならなし）です。
取消時は終了しても完了が偽の場合があります。出力取得を無効にしたタスクは、取得対象がないため両方真です。
プロセスの終了通知と出力のEOFは別です。必要なログを受け取り終えてからタスクを解放してください。
描画ループはタスクを自動で監視し、1回の監視で各ストリーム/進捗から最大16KiBを非ブロッキングで読みます。大量出力では子側にパイプの待ちが生じ得ます。

進捗取得を有効にすると、POSIXでは子の環境へ `HAJIMU_PROGRESS_FD=3` を渡します（親の環境は変更しません）。
対応するワーカーは、このFDへ `25.5\n` のように0〜100のASCII十進数を1行ずつ送ります。
ログに含まれる数字は進捗として解釈しません。不正行や128バイト以上の行は無視し、最後の有効値を保持します。
自分で `/bin/sh` を指定したワーカーなら `printf '25.5\n' >&3` の形で送信できます。通常の実行ファイルへこのシェル構文を自動適用することはありません。

任意のはじむ関数を第1引数へ渡す形式と、完了コールバックを開始時に保存する形式は未対応です。共有GC・クロージャの隔離実行を完成させたものではありません。
Windowsの進捗パイプは `HAJIMU_PROGRESS_HANDLE` に渡す10進数の継承HANDLEです。対応するネイティブワーカーは `WriteFile` で同じ行形式を書きます。CRTのFDではありません。継承するのは専用の標準入出力/進捗ハンドルだけで、親の他の継承可能ハンドルは渡しません。古い進捗環境変数も子から除外します。
Windowsは停止状態で起動して専用Jobへ収容した後に実行します。Jobへ収容できなければ起動失敗とし、追跡しない実行へ戻しません。親が先に終了してもJob内の子孫が残る間は実行中として保持し、取消/終了要求でJob全体を停止します。外部サービス経由でJob外へ作るプロセス等の追跡を保証するサンドボックスではありません。
標準入力の送信、完了の自動購読、Windows上のKaname全体のGUI実操作は残課題です。
通常の取消は終了回収を待ちません。描画ループ内の終了要求も、所有タスクを非ブロッキングで回収する間はOSイベント処理と待機画面の描画を継続します。
終了処理中は通常の編集/タイマーコールバックを止め、新規タスク起動やIME/タスク完了通知、対象ウィンドウの入力を抑止します。要求したフレームの実行中コードを途中中断するものではありません。
停止要求に失敗した場合は、PID/ウィンドウを保持して通常描画へ戻り、終了エラーを報告します。既に停止・回収した他のタスクを復活させることはありません。
描画ループ外からの `アプリ終了` は従来どおり同期破棄です。その待機中も出力を読みますが、イベントループなしでGUIを継続するものではありません。
POSIXでは親プロセスの終了後も子孫がパイプを保持するとEOFが遅れます。解放/アプリ終了時には親側のFDを閉じますが、既に終了した親から独立した子孫全体の停止は保証しません。
検査は `sh tests/check-tasks.sh`（`TASK_SANITIZE=1` でASan/UBSan）、`sh tests/check-application-controls.sh`、`tests/test_async_process.jp`、`tests/test_async_output.jp`、`tests/test_async_cancel.jp`、`tests/test_async_shutdown.jp` で実施できます。
`GUI_CLOSE_CAPTURE=/path/to/capture.ppm sh tests/check-application-controls.sh` は遅延回収中の待機画面を保存し、中央に描画画素があることも検査します。

開発中の `IME状態()` は `{"変換中": 真偽, "未確定文字列": 文字列}` を返します。
現在の未確定イベント接続はmacOSのみで、表示用文字列は最大127バイトのUTF-8境界までです。
単一行入力では未確定文字を下線表示し、候補位置を入力カーソルへ合わせます。
`テキストエリア` でも、折返し後の行に合わせて未確定文字を下線表示し、候補位置とカーソル位置を計算します。
編集位置が上下の表示範囲を外れるとスクロールして追従します。未確定文字は表示用に合成し、確定本文を変更しません。
単一行・複数行・パスワードの共通入力処理は、Ctrl/Cmd+Aの全選択、Shift+左右/Home/Endの選択、
選択範囲への入力/貼付け、範囲削除に対応します。通常入力のコピー/切取りは選択範囲だけを対象とし、
パスワード欄ではコピー/切取りを無効にしています。
単一行・複数行・パスワード欄で、クリックによる文字位置指定とドラッグ/Shiftクリックによる選択に対応します。
パスワード欄の位置はマスク文字の幅で判定します。複数行欄では折返し行の上下移動（Shift併用可）と、
欄外ドラッグ時の縦スクロールに対応します。上下移動は短い行を経由しても元の横位置を保持します。
操作開始領域は親の可視領域に制限し、IME変換中・無効状態・モーダル背景では選択操作を抑止します。
OSの実操作検査、折返し境界のカーソル親和性、横スクロール、単語/行単位の複数回クリック選択は残課題です。
`テキストカーソル位置(ラベル[,位置])` と `テキスト範囲選択(ラベル,開始,終了)` は、
同じID範囲で描画済みの入力欄に作用します。位置は0始まりのUnicode符号位置数（書記素数やUTF-8バイト数ではない）です。
通常操作の左右移動・Shift選択・Backspace/Delete・クリック位置は、utf8proc 2.12.0 / Unicode 18.0.0の拡張書記素境界を使います。
結合濁点・アクセント・国旗・肌色修飾・ZWJ列を途中で分けず、折返しとパスワードのマスクも同じ単位にそろえます。
公開位置APIとIME/AXの明示範囲指定は互換性のため符号位置単位のままです。APIが書記素内部へカーソルを置いた場合、通常の左右移動は境界へ移動し、範囲未選択の削除は書記素全体を対象とします。
共通入力の容量切詰めは書記素境界までとし、挿入できる書記素がない場合は選択部分を保持します。
この変更は字形合成エンジンの追加ではありません。結合記号の配置・複雑な文字組み・合字/カラー絵文字・双方向文字は別課題で、OS側の編集規則のUnicode版も共通エンジンと異なる場合があります。
検査は `GRAPHEME_SANITIZE=1 sh tests/check-grapheme.sh`、`sh tests/check-application-controls.sh` で実行できます。
同梱依存の来歴とライセンスは [vendor/utf8proc/README.hajimu.md](vendor/utf8proc/README.hajimu.md) を参照し、バイナリ再配布時もライセンスを同梱してください。
終端を超える整数は終端へ丸め、負数・小数・不正なラベルは失敗します。カーソルAPIは失敗時-1、範囲選択APIは真偽を返します。
変換中の公開APIからの位置変更は拒否します。
macOSの通常入力欄では、選択・未確定範囲・部分文書の問い合わせと、IMEの明示的な置換範囲をCocoaへ接続しています。
文書範囲はUTF-16からUTF-8へ変換し、絵文字のサロゲート途中の範囲を拒否します。置換イベントは入力欄ID・ウィンドウ世代を照合します。
通常の確定文字と基本の左右移動/選択/削除はOS側の文書状態でも順序どおり処理し、GUI側へ二重配送しません。
折返し上下移動などGUI側で扱うコマンドでは、次の描画まで文書同期を外して従来のフレーム入力へ戻します。
パスワード欄はOSへの部分文書公開から除外します。実IMEでの再変換・候補操作、複数ウィンドウでの配送、他OSの接続は未検証/未対応です。
`テキスト検索置換` は容量不足で-1を返して元の本文を保持し、成功時は入力バッファの長さとカーソルを同期します。
描画コールバック内で毎フレーム `IME合成(関数(状態): ... 終わり)` を呼ぶと、
未確定文字列が変わった場合に、その呼出元で一度だけ通知します。通知時は真、変更なしや無効な呼出は偽です。
状態には `変換中`・`未確定文字列`・`変更番号` が含まれ、変換終了の空文字も通知します。
同フレームまでの変更は最新状態へまとめます。購読登録ではなく、コールバックを保持しない明示的なポーリングです。
モーダル背景では通知を保留するため、必要なら予約したダイアログの内側で呼び出してください。
表示用に切り詰めた範囲の変更だけを検出します。長い未確定文字の全体表示、パスワード欄の変換表示、実IMEでのOS別検査は未完了です。

`モーダル予約("保存確認")` または `モーダル予約(["作品設定", "保存確認"])` を毎フレーム、背景の描画やショートカット処理より先に呼びます。
配列は親から子の順で最大16段、最後の名前だけが入力対象です。空/重複/長過ぎる名前や不正型は偽を返し、予約を変更しません。
`モーダルスタック()` は予約順序の独立した配列を返します。閉じた次のフレームは配列を短くし、すべて閉じる場合は `[]` または `""` を渡します。
開く操作は再配送せず、閉じると前のフォーカスと編集位置へ戻ります。次フレームに復帰先が表示/有効でなければテキストフォーカスを解除します。
新規コードは予約名に対する `ダイアログ開始(名前, 真)` と `ダイアログ終了()` を対で使ってください。
第3引数に `{"幅": 760, "高さ": 660}` を指定できます。省略した辺は従来の既定値を使い、画面内の余白16に収まるよう制限します。
未知の設定名、数値でない値、非有限値、0以下の寸法は開始前に拒否します。
覆われた親の入力状態は保持し、予約から外した段の入力バッファだけを解放します。同名のフォームを開き直すと新しい初期値を使います。

```hajimu
GUI.モーダル予約(["作品設定", "保存確認"])
もし GUI.ダイアログ開始("作品設定", 真) なら
    GUI.テキスト入力("名前", "作品名")
    もし GUI.ダイアログ開始("保存確認", 真) なら
        GUI.ボタン("保存")
        GUI.ダイアログ終了()
    終わり
    GUI.ダイアログ終了()
終わり
```

各範囲は独立したIDと内容クリップを持ち、外側のスクロール/パネル/横並び/グリッド/グループ/カード/ID/無効化/描画状態を復元します。
開始が偽の場合は終了を呼びません。終了は正常時に真、未閉鎖の子領域などを回復した場合や過剰終了には偽を返します。
フレーム末尾でも閉じ忘れた範囲を回復しますが、明示終了を推奨します。同フレームに同じ予約名を開始し直すことはできません。
終了後の残入力は消費し、背景へ返しません。旧 `ダイアログ` は従来どおりフレーム末尾までの暗黙範囲なので、新しい範囲付きAPIへの移行が必要です。
Escapeをアプリで処理する場合は、予約の前に取得してください。
予約より前に実行済みの背景操作は取り消せません。任意のキャンバス等の特殊な状態、旧部品のOSキー直接参照、OS実入力の全検査は未完了です。
Kanameの既存ダイアログは範囲付きAPIへ移行し、スクロール本文と固定操作行を分離しました。これは全ウィジェットの入力統一完了を意味しません。
`スクロール領域開始` は親のクリップと交差し、無効/背後の領域ではホイールを消費しません。端に達した入力は外側へ渡し、つまみは押した位置を保ってドラッグします。

開発中の `フォーカストラバーサル(真)` は描画コールバック内で明示有効化します。
ボタン・小ボタン・一覧項目・チェックボックス・ラジオボタンをTab/Shift+Tabで移動し、Enter/Spaceで実行できます。
単一行・パスワード・複数行入力も同じ移動順に含まれます。入力欄内のEnter/Spaceは編集用として保持します。
Tab移動は入力欄の編集後、現在フレームの有効・可視部品から決定します。文字入力とTabが同じフレームでも文字は元の欄へ反映し、移動先のOS入力先を次のイベント取得前に切り替えます。最大512個の一意なIDを登録し、それ以降の部品はTab順へ追加しません。
予約した最前面ダイアログだけを移動対象とし、新しく開いた際は最初の有効部品へ移動します。閉じる際は親のフォーカスを復帰させます。IME変換中は移動しません。空白クリック後に元の欄へ勝手に戻りません。
一覧・コンボは上下/Home/Endで選択します。コンボは閉じた状態では値を変更し、開いた状態ではEnter/Spaceで候補を確定、Escapeで取消します。Escapeはアプリへ渡す前にコンボが消費し、Tabではコンボを閉じて移動します。選択可能行もEnter/Spaceで切り替えられます。
Kanameで明示有効化しています。特殊なツリー/テーブル/キャンバス/メニューの全操作、スクロール領域外の部品への自動移動、実OSキー入力の網羅検査は未完了です。
全体の実装・検証計画は [APPLICATION_FOUNDATIONS_PLAN.md](docs/APPLICATION_FOUNDATIONS_PLAN.md) を参照してください。

`リスト` のスクロール状態はウィンドウ単位・ID単位で最大256件保持します。
上限を超える場合は最も長く使われていない状態を破棄し、再表示時は先頭へ戻ります。
同じウィンドウで同名の一覧を複数使う場合は `ID範囲開始` で区別してください。
描画では表示中の行だけを走査します。無効化中はホイール操作でも移動しません。

- `ボタン("保存", {"有効": 偽})`: 無効時はクリック不可・補助色表示。外側の無効化範囲を解除しません。
- `ボタン("保存済み", {"ID": "save"})`: 文言が変化しても操作対象のIDを維持します。
- `一覧項目("project-id", "作品名", "保存先", 偽)`: タイトルと補足の2行を表示し、行内で押して離した時、またはフォーカス中のEnter/Spaceで真を返します。補足が空文字なら一行高へ縮めます。第4引数は選択中の表示で、省略可能です。選択中でも操作しなければ偽です。IDは項目の名前や位置ではなく、変更しない識別子を渡してください。矢印による行間移動は未対応です。
- `省略テキスト("作品名", 180)`: UTF-8文字境界を保って1行に省略。改行以降も省略扱いです。幅ゼロでは描画せず、行の高さは保持します。
- `利用可能幅()`: 次の幅指定を消費せずに残り幅を取得します。

長いボタン名も省略されます。全文が必要な場合は直後の `ツールチップ()` で補ってください。
macOSでは `sh tests/check-application-controls.sh` で幅計算・UTF-8境界・押下/解放・無効状態を検証できます。

`利用可能幅()` は現在のレイアウト領域の幅を返します。
`省略テキスト(文字列 [, 最大幅])` はUTF-8を壊さず末尾を省略する1行表示です。
全文の確認には続けて `ツールチップ(文字列)` を指定できます。

v14.6では保存と終了の安全性を支援するAPIを追加しています。

- `ファイルロック取得(パス)` は非待機のOSロックを取得し、整数ハンドル、失敗時は `-1` を返します。`ファイルロック解放(ハンドル)` またはプロセス終了で解放します。ロックファイルを削除しないでください。
- `ディレクトリ移動(元, 先)` は、元が実ディレクトリで先が存在しない場合に移動します。失敗時は偽を返します。
- `終了確認設定(アプリ, 関数)` はウィンドウの終了要求を確認します。関数が真を返した場合だけループを終了します。関数のスコープはアプリ終了まで維持してください。トップレベル関数の利用を推奨します。
- `アプリ終了要求(アプリ)` は同じ確認経路を通ります。`アプリ終了` は確認を省略する確定終了です。
- 描画ループ実行中の終了は回収完了までウィンドウを保持し、確認済みの終了要求で確認関数を再度呼びません。同じアプリの描画ループへの再入は拒否します。
- `アプリ終了状態(アプリ)` は `状態`（実行中/終了処理中/停止/不明）、`未回収タスク`、累積の `終了待機フレーム`、直近の `エラー番号` を返します。
- `OS終了要求待ち` はOSの閉じる要求が届き、コールバック後の終了確認へまだ渡していない間だけ真です。描画側で書き出し公開などの副作用より先に取消を予約できます。要求を消費/許可するAPIではなく、終了確認の呼出規約は変わりません。
- `アプリ入力状態(アプリ)` は `有効`、`保留数`、`破棄入力数`、`OSキュー破棄入力数`、`共通キュー破棄数`、`入力リセット待ち` を返します。破棄入力数はアプリ別キューから取り除いた入力数（上限超過またはOSリセットによるもの）、OSキュー破棄入力数はそのウィンドウで通知を受け取った共通キュー超過破棄数です。共通キュー破棄数はそのGUIループで拒否した不明/古い送信元の累積数で、OSキュー内の拒否数は含みません。
- 入力は送信元ウィンドウと世代を照合し、各アプリに通常64イベントまで保留します。OS共通キューは通常255イベント、別枠の終了/最新サイズ/リセット状態を持ちます。共通キュー超過時は全登録ウィンドウへリセットを配送し、古い保留編集を先に捨てます。超過時の入力は復元せず、文字の途中反映を避けるため破棄します。
- GUIは1フレームに1回、最大256件のOSイベント取得を行い、保留キューのフォーカス/捕捉/押下状態を必要に応じて解除します。低レベルのネイティブ登録上限は32ウィンドウ（GUIアプリ上限は従来どおり8）。OSからの終了確認はそのフレームの編集反映後に行います。
- 複数ウィンドウの同時描画/入れ子ループ、全ウィジェットの入力消費、Windows/Linuxの実機検査は未完了です。入力取得回数の上限は、個々のOSコールバックやアプリ処理の実行時間まで制限するものではありません。
- `停止` は描画ループと所有タスク回収が終わった状態で、ウィンドウの破棄とは別です。ループ外で `アプリ終了` を呼んで破棄します。破棄後/不正なIDは `不明` です。

egui のシンプルさと PyQt の本格ウィジェットを融合した、完全日本語 API GUI ライブラリです。

## 特徴

- **即時モード GUI** — `GUI.ボタン("ラベル")` が `真/偽` を返すシンプル設計
- **完全日本語 API** — 関数名・引数名すべて日本語
- **高品質描画** — 自作レンダラ (hjp_render.c) によるアンチエイリアス付きベクター描画
- **日本語フォント内蔵** — Noto Sans CJK JP を同梱（追加設定不要）
- **Retina 対応** — macOS の高解像度ディスプレイに自動対応
- **依存ゼロ** — Qt/GTK/SDL2 不要、自作プラットフォーム層のみ
- **クロスプラットフォーム** — macOS (Cocoa) / Linux (X11+GLX) / Windows (Win32+Win64)
- **ライト／ダークテーマ** — 意味色を上書きできる動的テーマを搭載
- **宣言的 UI** — React 風の仮想ノードツリー + O(n) 差分レンダリング (`VUI.*` API)
- **ホットリロード** — `.jp` ファイル変更を自動検知し即時反映
- **DevTools** — F12 でオンスクリーン FPS グラフ・ウィジェットインスペクタを表示

## セットアップ

### 必要な依存

**外部依存ライブラリは不要です。** OS標準のグラフィックスAPI のみ使用します。

| OS | 必要なもの |
|---|---|
| macOS | Xcode Command Line Tools (`xcode-select --install`) |
| Linux | X11 + OpenGL (`sudo apt install libx11-dev libgl-dev`) |
| Windows | Visual Studio / MinGW (Win32 API) |

### ビルド & インストール

#### パッケージマネージャ（推奨）

はじむ内蔵のパッケージマネージャを使うと、コンパイル不要で一行でインストールできます。

```bash
hajimu パッケージ 追加 ReoShiozawa/hajimu_gui
```

プロジェクトの `hajimu.json` に依存として記録されるので、チーム内で共有する際に導入コストがかかりません。

```bash
# 別のメンバーが hajimu.json の依存を一括インストール
hajimu パッケージ インストール
```

#### ソースからビルド

手動でビルドする場合:

```bash
git clone https://github.com/ReoShiozawa/hajimu_gui.git
cd hajimu_gui
make
make install
```

macOSのObjective-C実装にはARCが必要です。付属Makefileは `-fobjc-arc` を有効にします。独自のビルド手順でも同じ指定を維持してください。

メモリと寿命の回帰検査は、macOSで次を実行します。20ウィンドウのdelegate保持・破棄、文字幅10,000回、128パスを含む10,000フレームのASan検査を含みます。

```sh
sh tests/check-macos-lifetime.sh
```

基本ウィジェットの一時引数解放は、`hajimu_plugin_borrows_arguments` に対応したHajimuランタイムで有効になります。タイマー・モデルなど引数を保持するAPIは対象外です。公開ABIの構造体は変更していません。

## 使い方

```
取り込む "hajimu_gui" として GUI

// アプリ作成
変数 アプリ = GUI.アプリ作成("私のアプリ", 800, 600)

// 状態
変数 カウンター = 0
変数 同意 = 偽

// 描画ループ
GUI.描画ループ(アプリ, 関数():
    GUI.見出し("Hello, はじむ GUI!", 1)
    GUI.テキスト("即時モードGUIのデモです")
    GUI.セパレーター()

    もし GUI.ボタン("カウント +1") なら
        カウンター = カウンター + 1
    終わり
    GUI.テキスト("カウント: " + 文字列(カウンター))

    同意 = GUI.チェックボックス("利用規約に同意する", 同意)
終わり)

GUI.アプリ終了(アプリ)
```

## API リファレンス

### Phase 1: コア (v0.1.0)

| 関数 | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `アプリ作成` | タイトル, 幅, 高さ | 数値 | ウィンドウ付きアプリを作成 |
| `描画ループ` | アプリ, コールバック | — | メインループ開始 |
| `アプリ終了` | アプリ | — | アプリを終了・リソース解放。描画中の呼び出しも安全に遅延処理 |
| `ウィンドウサイズ` | アプリ | {幅, 高さ} | 現在のウィンドウサイズ |
| `ウィンドウタイトル` | アプリ, タイトル | — | タイトルバー変更 |
| `ウィンドウリサイズ` | アプリ, 幅, 高さ | — | ウィンドウサイズ変更 |
| `フレームレート` | アプリ, FPS | — | 目標FPS設定 (デフォルト: 60) |
| `背景色` | 色 | — | 背景色設定 (パック色 or 16進文字列) |
| `色` | R, G, B [, A] | 数値 | RGBA色を生成 (0–255) |
| `色16進` | "#RRGGBB" | 数値 | 16進数から色を生成 |

`Escape` はアプリを強制終了せず、`キー押下("エスケープ")` または
`ショートカット("エスケープ")` で通常のキー入力として受け取れます。

| `ボタン` | ラベル [, オプション] | 真偽 | クリックで `真` を返す |

| `ラジオボタン` | ラベル, グループ, 現在値 | 文字列 | 選択されたラベルを返す |
| `スライダー` | ラベル, 値, 最小, 最大 | 数値 | ドラッグで値変更 |
| `プログレスバー` | 値 [, 最大] | — | 進捗表示 (デフォルト最大: 100) |
| `セパレーター` | — | — | 水平区切り線 |
| `スペーサー` | [高さ] | — | 余白 (デフォルト: 16px) |
| `ツールチップ` | テキスト | — | 直前ウィジェットのホバーヒント |
| `ID範囲開始` / `ID範囲終了` | ID / — | 真偽 | 同じ表示名のウィジェットを領域ごとに一意化 |

### Phase 3: テキスト入力 (v0.3.0)

| 関数 | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `テキスト入力` | ラベル, 値 [, オプション] | 文字列 | 単行テキスト入力 |
| `パスワード入力` | ラベル, 値 | 文字列 | マスク付き入力 (●表示) |

### 制作ツール向けレイアウト (v14.3.0)

| 関数 | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `分割バー` / `split_bar` | ID, 方向, 長さ, 位置, 最小, 最大 | 数値 | 全長をドラッグでき、方向に合うカーソルを表示する分割バー |
| `無効化開始` / `無効化終了` | — | — | 範囲内の操作を無効化し、半透明で表示 |
| `ツールバー開始` | [高さ] | — | 単段または指定高の複数段ツールバーを開始 |

### ファイル・プロセス操作 (v14.1.0)

| 関数 | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `ファイルコピー` / `file_copy` | コピー元, コピー先, 進捗関数(省略可) | 真偽 | 一時ファイルへコピーし、成功時だけ置換。進捗関数は完了/総バイト数を受け、真以外で取消 |
| `ファイル削除` / `file_delete` | パス | 真偽 | 通常ファイルを削除（ディレクトリは対象外） |
| `ファイル置換` / `file_replace` | 一時ファイル, 保存先, 上書き許可=真 | 真偽 | 原子的に公開。第3引数が偽なら既存の保存先を置換しない |
| `外部プロセス起動` / `process_launch` | 実行ファイル, 引数配列 | 真偽 | シェルを介さず別プロセスを起動 |
| `実行ファイルパス` / `executable_path` | なし | 文字列 | 現在のHajimu実行ファイルの絶対パス |

| `マウス位置` | — | {x, y} | マウスの現在位置 |
| `マウスクリック` | — | 真偽 | このフレームでクリックされたか |
